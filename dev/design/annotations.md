# Annotation contract

Repoaxis annotations are durable user/agent-authored memory stored separately from generated structural state.

- `annotations` is not regenerated by the indexer.
- Each writable annotation is keyed by a canonical node ID and currently contains one `agent_note` string.
- New annotations resolve against the current index and reject ambiguous or missing targets.
- Annotation mutations validate the index before writing and replace the index file atomically.
- `repoaxis build` preserves valid annotations while replacing generated nodes, edges, Git projections, and refresh metadata.
- Notes whose node disappears remain as orphaned annotations. They can be listed, read, and explicitly cleared by exact stored node ID.
- S08 does not change schema version 1 or turn annotations into generated analysis.
